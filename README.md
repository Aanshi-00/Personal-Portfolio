# IN THE MAKING. — Aanshi Dangi

> Still learning. Still building. Still becoming.

A personal portfolio website designed and developed by **Aanshi Dangi**, a Computer Science Engineering student exploring Web Development, Artificial Intelligence, and Cybersecurity.

The portfolio represents my journey of learning, experimenting, creating projects, and continuously growing as a developer.

---

## ✦ About the Project

This is a personal portfolio website built to showcase my technical skills, projects, educational journey, certifications, and interests.

The website focuses on a minimal yet cinematic experience, combining modern typography, subtle animations, interactive elements, and a distinctive visual identity.

It is designed to reflect the idea that development is a continuous process — always learning, always building, and always becoming.

---

## ✦ Design Philosophy

The website follows a minimalist and cinematic design approach.

- **Theme:** Minimal, elegant, and modern.
- **Visual Style:** Soft black, ivory, dusty plum, and champagne accents.
- **Typography:** Instrument Sans.
- **Animations:** Smooth transitions and scroll-based interactions.
- **Layout:** Clean sections with generous spacing.
- **Experience:** Responsive and interactive across devices.

### Key Design Elements

- Light and dark theme toggle.
- Animated hero section.
- Interactive orbital project visualization.
- Scroll-triggered reveal animations.
- Custom glowing cursor for desktop devices.
- Smooth scrolling and transitions.
- Responsive navigation menu.

## ✦ Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Aanshi-00/Personal-Portfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd Personal-Portfolio
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the Website

Open `index.html` using the Live Server extension in VS Code.

Alternatively, open `index.html` directly in your browser.

## ✦ Customization

The portfolio can be customized by editing the following files:

- `index.html` — Update content, sections, links, and personal information.
- `style.css` — Modify colors, typography, layouts, and animations.
- `script.js` — Modify interactive functionality, theme switching, cursor behavior, and scroll animations.

Certificates can be added or replaced inside the `certificates/` directory.
